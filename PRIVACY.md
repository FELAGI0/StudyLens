# Privacy Policy

Last updated: 2026-10-09

StudyLens is a Chrome extension that analyzes screen content using AI. This policy describes what data we process and how we protect it.

## What data is processed

- Screenshots of the selected screen area (only when you trigger capture via hotkey)
- Text of the task (if you type it manually)

## How data is used

- Screenshots are sent to an API provider (OpenAI-compatible endpoint or StudyLens backend) for analysis
- Analysis result is returned to the response panel

## What is NOT done

- We do not store your screenshots on servers
- We do not collect usage statistics
- We do not share data with third parties
- We do not track your browsing activity

## Mode "Own key"

- You use your own API key
- Requests go directly to your chosen API provider
- Key is stored only in your browser (chrome.storage.local)

## Mode "Password"

- Requests go through StudyLens server (study-lens-backend.onrender.com)
- Server forwards them to API provider
- Screenshots are not logged on the server

## Changes to this policy

We may update this policy from time to time. Changes will be posted on this page.
