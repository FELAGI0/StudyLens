## Full description

StudyLens - AI-ассистент для обучения и работы с текстом, кодом и задачами прямо в браузере.

Выдели область экрана горячей клавишей и получи подробный разбор за секунды. Работает с математикой, программированием, естественными науками, переводом текста.

Возможности:
- 5 режимов ответа: Объясни, Кратко, Пошагово, Переведи, Найди ошибку
- Горячие клавиши для каждого режима
- Рендер формул (LaTeX) и кода (Markdown)
- Стриминг ответа (текст появляется постепенно)
- Тёмная тема, минималистичный дизайн

Два способа использования:
- Со своим API-ключом (OpenAI-совместимый endpoint)
- По паролю через сервер StudyLens

Идеально для:
- Учёбы (разбор задач, объяснение тем)
- Работы с кодом (поиск ошибок, объяснение алгоритмов)
- Переводов текста
- Изучения иностранных языков

Приватность:
- Скриншоты не сохраняются на серверах
- Ключ хранится только в вашем браузере
- Никакого трекинга
